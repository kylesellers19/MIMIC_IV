## 1. Data source and population

We used MIMIC-IV v3.1 (`hosp` module) linked to MIMIC-IV-Note v2.2, a single-centre, de-identified, credentialed critical-care and hospital database (Johnson et al. 2023; MIMIC-IV-Note citation unverified — see `docs/references/unresolved.md`, entry R12). All work was performed on locally held credentialed extracts; no credentialed data, derivative, embedding, model weight or prediction left the analysis machine.

The unit of analysis is the **hospital admission** (`hadm_id`). MIMIC-IV v3.1 `hosp` contains 546,028 admissions across 223,452 subjects. Diagnosis rows are keyed by `(subject_id, hadm_id, seq_num, icd_version)`: 116 `(subject_id, hadm_id, seq_num)` groups are duplicated because a single stay carries both an ICD-9 and an ICD-10 row for the same sequence position, so `icd_version` is part of the key (`docs/data_quality_report.md` §1.4).

Note linkage was established by `hadm_id` for inpatient documents. MIMIC-IV-Note v2.2 holds 331,793 discharge summaries (one per admission, 145,914 subjects) and 2,321,355 radiology reports (237,427 subjects, 309,670 distinct admissions). 1,176,597 radiology reports (50.7%) carry a NULL `hadm_id`; these are outpatient studies, not linkage failures, and span 188,882 subjects of whom 117,163 are in the analysis population (`docs/note_coverage.md`). They were retained and linked to admissions by `subject_id` and charttime, because incidental steatosis on outpatient imaging is a core mechanism of the study. Discharge text is long (median 9,847 characters, 95th percentile 18,619, maximum 60,381); radiology text is short (median 781 characters).

The **locked analysis population** is admissions in the analysis population with at least one linked clinical note (discharge **or** radiology): **373,992 admissions / 161,119 subjects**, of which **5,740 are MASLD code-positive** and 368,252 code-negative (`docs/analysis_population.md`, `docs/tables/table0.md`, `docs/run_2026-09-19/results/cohort_flow.json`). No temporal window was imposed (§2).

## 3. Data-quality assessment

Data quality was assessed with the harmonized terminology and framework of Kahn et al. (EGEMS 2016;4(1):1244; doi:10.13063/2327-9214.1244), across its conformance, completeness and plausibility dimensions; the full report is `docs/data_quality_report.md`.

- **Conformance.** `hadm_id` is a clean key (0 duplicate `(subject_id, hadm_id)` pairs; 0 full-duplicate rows in any of the four core tables). Referential integrity is intact: no diagnosis row references an absent admission, no NULL `hadm_id` in `diagnoses_icd`, no admission references an absent subject. ICD codes are stored space-padded and must be trimmed, and ICD-9/ICD-10 code spaces overlap, so matching is version-aware.
- **Completeness.** Value-level missingness is explicit rather than hidden (no empty-string or whitespace-only values in any VARCHAR column). Structurally missing fields behave as expected (`deathtime` 97.8% NULL). Administratively missing fields are material: `discharge_location` 27.4%, `marital_status` 2.5%, `insurance` 1.7%. Laboratory coverage among coded-positive subjects is excellent for liver-function tests, glucose and platelets (93.8–99.9%) and moderate for the lipid/glycaemic panel (HbA1c 67.6%, triglycerides 66.7%, HDL 61.3%).
- **Completeness differential by coding status** is the finding that matters for this study. Coded-positive admissions differ from the rest most strongly on documentation intensity rather than on clinical values: diagnoses per admission SMD +0.68, admission type +0.41, race +0.33, language +0.20, marital status +0.19, length of stay +0.18, insurance +0.17. Laboratory *availability* differentials of approximately +0.47 for ALT/AST/alkaline phosphatase/bilirubin survive restriction to the locked population, while short-stay-driven analytes (glucose, platelets) largely collapse (`docs/analysis_population.md`).
- **Plausibility.** `anchor_age` spans 18–91, where 91 is the MIMIC age cap (ages ≥ 89 are collapsed) and not a real maximum; 175 admissions have negative length of stay and 5 are zero, with a maximum of 515.6 days. Laboratory `itemid` label searches over-match across body fluids (for example, an HDL label search also matches a total-cholesterol/HDL ratio, and an alkaline-phosphatase search matches leukocyte ALP), so downstream analyses use an explicit serum itemid list.
- **Race is recorded per admission and is not stable per person:** 11,900 subjects (11.9% of those with multiple admissions) carry more than one distinct `race` value across their own stays, mixing hierarchy artefacts with genuinely conflicting values.

Options arising from each finding, with what each would change, were recorded as decisions rather than resolved silently (`docs/data_quality_report.md` Part 2).

## 4. ICD phenotype (the code axis)

The code-positive phenotype uses a pre-specified code set, fixed in `sql/masld_coded.sql` before any comparison was run and not expanded since:

| ICD version | Code | Meaning |
| --- | --- | --- |
| ICD-10-CM | K76.0 | Fatty (change of) liver, not elsewhere classified |
| ICD-10-CM | K75.81 | Nonalcoholic steatohepatitis (NASH) |
| ICD-9-CM | 571.8 | Other chronic nonalcoholic liver disease |
| ICD-9-CM | 571.9 | Unspecified chronic liver disease without mention of alcohol |

Two correctness guards are applied: codes are **trimmed** of the trailing spaces with which MIMIC pads them to fixed width, and matching is **version-aware**, joining on `(icd_version, code)` jointly because the ICD-9 and ICD-10 code spaces overlap and a code-only match yields false positives. An admission is code-positive if any diagnosis row on that admission matches the set; `seq_num` position is not used in the definition.

**The status of 571.9 is an OPEN question and is not resolved in this draft.** The 2021 expert-panel consensus on administrative coding for fatty-liver research (Hagström et al., *Hepatology* 2021;74(1):474–482; doi:10.1002/hep.31726; PMID 33486773) lists ICD-9 571.8 and ICD-10 K76.0 for the disease overall and ICD-10 K75.8 for steatohepatitis, and does **not** list 571.9; K75.81 is the ICD-10-CM subdivision of K75.8 and is consistent with that table. A full sensitivity analysis is reported in `docs/sensitivity_5719.md` (results `docs/run_2026-09-19/results/sens_5719.json`): 40 admissions (38 subjects) are code-positive solely through 571.9, so the code-positive count would fall from 5,740 to 5,700. Under the primary note definition the cross-tabulation would become A 5,015 / B 22,811 / C 685 / D 345,481, moving the recovery share from 81.93% to 81.98% and the corroboration share from 87.58% to 87.98%. The consequential effect is on the chart-review sample rather than the cross-tabulation: between 1 and 10 already-drawn charts would change cell, which changes per-cell sample sizes and therefore the sampling weights (revised weights in the same document). Because weights are fixed at sampling time, this must be settled before adjudication begins. The decision and its options are recorded as D-01 in `docs/run_2026-09-19/DECISIONS_FOR_KYLE.md`. **Final choice: [PENDING researcher decision D-01].**

## 5. Note phenotype (the note axis)

The note-based phenotype is a frozen, versioned, computable rule (`docs/note_phenotype_spec.md`, VERSION 1.1.0, frozen 2026-08-17; implementation `scripts/note_phenotype.py`, function `classify_note()`). The construct is *"was steatosis documented and available to the clinician at this admission"* — a documentation phenotype, not an adjudicated label.

**Three-tier lexicon.** Tier A (definite steatosis) is the primary axis and contains explicit disease terms (`hepatic steatosis`, `fatty liver`, non-/nonalcoholic fatty liver disease and steatohepatitis and their hyphenation variants, NAFLD, NASH, MASLD, MASH, NAFL), the stems `steatosis`/`steatotic`/`steatohepatit*`, and a set of explicit "fatty X" phrases. Tier B (imaging signs: increased hepatic echogenicity, echogenic liver, increased echogenicity, low attenuation, decreased hepatic attenuation) is nonspecific — fibrosis and other chronic liver disease produce the same signs — and is used for sensitivity analysis only, never as the primary axis. Tier C is a Tier A hit that passes scoping and negation but stands under a hedge cue (`may represent`, `cannot be excluded`, `concerning for`, `suggestive of`, `possible`, `question of`, `versus`, `differential includes`, and documented variants); Tier C is reported separately and merged neither way.

**Mandatory anatomical scoping.** Every trigger carries a scope mode: `none` (inherently hepatic), `standard` (pass if a liver/hepatic token is within 10 tokens, or if the sentence contains no competing organ), or `strict` (pass only with an affirmative liver/hepatic token within 10 tokens; the "no competing organ" fallback is disabled). Competing organs are pancreas, gallbladder, marrow, omentum, mesentery, spleen, kidney, breast and thymus and their adjectival forms; if the *nearest* organ token is a competing organ, the hit is suppressed and attributed to it. The scoping design follows published VA/VACS-based hepatic-steatosis NLP work (Hepatology Communications, 2024; **unverified reference** — the repository records no author or identifier and the exact citation is to be confirmed by the study team; a single candidate returned by PubMed is listed in `docs/references/unresolved.md`, entry R08, and must be confirmed before submission).

**Context assertion.** Negation and context status are determined by a **reimplementation of ConText** (Harkema H, Dowling JN, Thornblade T, Chapman WW. *ConText: an algorithm for determining negation, experiencer, and temporal status from clinical reports.* J Biomed Inform. 2009;42(5):839-51; doi:10.1016/j.jbi.2009.05.002; PMID 19435614), which extends NegEx (Chapman WW, Bridewell W, Hanbury P, Cooper GF, Buchanan BG. *A simple algorithm for identifying negated findings and diseases in discharge summaries.* J Biomed Inform. 2001;34(5):301-10; doi:10.1006/jbin.2001.1029; PMID 12123149). The algorithm was reimplemented in-repository with the published trigger lexicons rather than run from an external distribution, for Python 3.14 reproducibility; this is recorded as a limitation. Scope is sentence/segment-level, with segments split at termination terms (`but`, `however`, `although`, `though`, `yet`, `except`, `aside from`, `nevertheless`, `otherwise`); pre-cues act forward and post-negation cues backward; pseudo-negation phrases are blocked. Negation excludes; family/experiencer excludes; **historical/temporality flags but does not exclude** and is reported separately; hypothetical/hedged routes the hit to Tier C. Cue matching is token-level with word boundaries. Per-hit classification precedence is: anatomical suppression → family → negation → hedged (Tier C) → affirmed positive (with optional historical flag).

**Versioning and the v1.0.0 → v1.1.0 revision.** Both versions are git-tagged (`note-phenotype-v1.0.0`, `note-phenotype-v1.1.0`). The revision was made on the basis of the rule's own behaviour on the corpus, documented in `docs/fatty_trigger_diagnostic.md`; **no adjudicated, gold-standard or reference-standard data was used at any point**, and the specification explicitly forbids iterating against the gold standard. The substantive change was the removal of bare `fatty` as a Tier A trigger. The diagnostic showed that bare `fatty` uniquely made 8,142 admissions note-positive (code-positive 87, code-negative 8,055), that the phrase composition of those unique contributors was dominated by `fatty acids` (3,915 hits, a lipid/dietary term) together with `fatty foods`, `fatty meal`, `fatty tissue` and similar non-hepatic uses, and that most hits passed scoping with no liver or hepatic token in the sentence. Four further changes accompanied it: plausible phrasings (`fatty replacement`, `fatty deposition`, `fatty degeneration`, `fatty metamorphosis`, `fatty infiltrate`) were promoted to explicit Tier A phrases under **strict** scoping; `fatty atrophy` was deliberately not added because in radiology it more often describes muscle, pancreas or marrow; `fatty infiltration` was tightened to strict scoping by researcher ruling after a fallback audit; and a correctness bug was fixed whereby v1.0.0 matched context cues by substring, so `no` fired inside "normal" and "known" and falsely negated true positives — token-level matching restored 855 admissions (47 of them code-positive) and reduced negation exclusions from 2,287 to 941. The aggregate effect on inpatient-linked Tier A positives was 27,293 (v1.0.0) → 18,417 (v1.1.0): 9,105 lost (code-positive 92, code-negative 9,013) and 229 gained. This is reported to show how the revision moves the recovery zone, not as validation. The v1.0.0 rule is retained as sensitivity definition (d).

**The freeze.** The specification and the implementation were frozen and tagged **before** the cross-tabulation was built and before any chart adjudication. Any further change requires a new version string. (One two-line post-tag change exists in `scripts/note_phenotype.py`: a hard-coded population path was replaced by an import of the project's population constant. Lexicon, context handling and classifier logic are byte-identical to the tag; this is recorded in `docs/run_2026-09-19/RUN_LOG.md` Phase 0.2, and whether to re-tag as v1.1.1 is [PENDING researcher decision].)

**Outpatient radiology linkage.** Radiology reports with NULL `hadm_id` are linked to an admission by `subject_id` and by note `charttime` relative to `admittime`, with a primary window of **365 days before to 30 days after** admission and a sensitivity window of 90 days before to 30 days after. The window is lookback-dominant because the construct is availability of the information to the clinician at this admission; the short forward window prevents post-admission and post-coding information from defining the phenotype.

**Rule behaviour on the locked population** (behaviour only; no accuracy metric, because no reference standard exists at this stage): Tier A inpatient-linked 18,417 admissions (4.9%); Tier A + Tier B 22,248 (5.9%); Tier C hedged 1,030 (0.3%). Tier A sources: discharge only 7,726, radiology only 4,215, both 6,476. Suppressions and flags: negation 941, family 106, historical **flagged** 1,998, anatomical suppression 6,540 (of which 4,590 were `no_liver_evidence` under strict scoping, 883 pancreas, 305 gallbladder, 257 renal). Adding outpatient radiology in the primary window raises Tier A positives from 18,417 to **27,826**; in the sensitivity window, to 22,759.

## 6. Subclassification of steatotic liver disease (Rinella et al. 2023)

Steatotic-liver-disease subclassification follows the multisociety Delphi consensus (Rinella ME, Lazarus JV, Ratziu V, et al. *A multisociety Delphi consensus statement on new fatty liver disease nomenclature.* J Hepatol. 2023;79(6):1542-1556; doi:10.1016/j.jhep.2023.06.003; PMID 37364790). MASLD is defined **positively** — hepatic steatosis plus at least one cardiometabolic risk factor — and, unlike NAFLD, does not require exclusion of other liver disease. Full detail is in `docs/sld_subclassification.md`.

**The five cardiometabolic criteria** were each operationalized as *diagnosis code OR laboratory/vital value over threshold OR qualifying medication*, with an admission counted **unascertainable** for a criterion when it has none of the three. Per-criterion positivity and unascertainability on the locked population were: overweight/obesity 53.6% positive / 22.0% unascertainable; dysglycaemia 61.2% / 14.7%; hypertension 68.6% / 11.8%; hypertriglyceridaemia 37.3% / **60.1%**; low HDL 37.2% / **61.8%**. At least one criterion was met by 88.4% of admissions using codes, labs and vitals alone and by 89.8% with qualifying medications added (+1.42 points, 5,301 admissions added by medication alone); 2.7% were unascertainable on all five. The cardiometabolic requirement is therefore close to non-binding in this inpatient population, which is itself a reportable finding.

**Medication-class rulings.** Medications enter only in the residual where neither a code nor a measurement exists, so restrictiveness there costs little and protects specificity. Matching is by drug name (with GSN/NDC retained for audit), restricted to the locked population, with the ophthalmic route excluded. Explicit rulings: **beta-blockers excluded** from the hypertension criterion (the 13,080 admissions positive by beta-blocker alone carry no hypertension code and no blood pressure ≥ 130/85 anywhere in the stay; the residual indication is heart failure, rate control or post-myocardial-infarction); **insulin excluded** from the dysglycaemia criterion (the 8,251 positive by insulin alone have no dysglycaemia code, no HbA1c ≥ 5.7% and no glucose ≥ 100 mg/dL, and the order table cannot separate home insulin from inpatient sliding scale; orders explicitly indicated for hyperkalaemia are excluded regardless); **metformin included** (102 admissions positive by metformin alone); **hydralazine, metolazone and alpha-blockers excluded** from the hypertension criterion (intravenous hypertensive-urgency and heart-failure regimens; metolazone would preferentially misclassify the recovery zone, 12.8% of which carries cirrhosis codes; alpha-blockers are dominated by benign prostatic hyperplasia). Ophthalmic timolol and dorzolamide-timolol are excluded on route; clopidogrel and ticlopidine are excluded from lipid-lowering as antiplatelets. Class totals are counted as distinct admissions per class, after a diagnosed and corrected counting error in which per-drug distinct-admission counts had been summed within a class.

**MetALD thresholds cannot be applied.** The consensus defines MetALD by quantified alcohol intake (140–350 g/week in females, 210–420 g/week in males). MIMIC-IV contains no quantified intake. Alcohol status is therefore proxied by ICD codes, which capture **disorder-level** use, not the moderate band the definition specifies. This is a proxy, not an implementation of the criterion, and is stated wherever a MetALD count appears. Among note-positive admissions, subclassification gives MASLD 22,209 (79.8%), MetALD 4,308 (15.5%), ALD 386 (1.4%), cryptogenic 748 (2.7%), unclassifiable 175 (0.6%). MetALD has no ICD code at all, so this group is invisible to the code axis by construction.

Medication exposure is established from `prescriptions` (MIMIC-IV's medication-*order* table), which is sufficient for "current treatment" as the consensus specifies; `pharmacy` (dispensing-level detail relevant to adherence and dosing) was not fetched and this is recorded as a completeness limitation.

## 7. Cross-tabulation and the recovery share

The two computable phenotypes were crossed at admission grain on the locked population (`docs/aim1a_crosstab.md`; anchors reproduced in `docs/run_2026-09-19/results/integrity_gate.json`, all 14 integrity checks passing). Cells are labelled A = code+/note+, B = code−/note+, C = code+/note−, D = code−/note−.

Four definitions were computed:

| Definition | A | B | C | D |
| --- | --: | --: | --: | --: |
| (a) v1.1.0, inpatient-linked notes only | 4,805 | 13,612 | 935 | 354,640 |
| **(b) v1.1.0 + outpatient radiology −365/+30 — PRIMARY** | **5,027** | **22,799** | **713** | **345,453** |
| (c) v1.1.0 + outpatient radiology −90/+30 (window sensitivity) | 4,908 | 17,851 | 832 | 350,401 |
| (d) v1.0.0, inpatient-linked (rule-version sensitivity) | 4,850 | 22,443 | 890 | 345,809 |

Under the primary definition (b) there are 27,826 note-positive admissions. Two descriptive shares are defined: the **recovery share** = B ÷ (A + B) = **81.9%**, the proportion of note-positive admissions carrying no MASLD code; and the **corroboration share** = A ÷ (A + C) = **87.6%**, the proportion of code-positive admissions whose notes also document steatosis. Rule-version dependence is isolated by comparing the inpatient-linked code−/note+ cell across rule versions: 13,612 under v1.1.0 (a) versus 22,443 under v1.0.0 (d), so the pre-revision lexicon would have made that cell 8,831 admissions (+64.9%) larger, driven by bare-`fatty` false positives that were predominantly code-negative. Definition (d) is a sensitivity reference that lets the manuscript state how much the count depends on the lexicon revision; it is not a competing estimate.

**The recovery share is not a recovery estimate, and it is not the headline.** It is a comparison of two computable phenotypes — an ICD code set and a frozen lexical rule — neither of which is a reference standard. The code−/note+ cell is a **sampling stratum**, not a count of missed cases. The headline Aim 1a quantity is the inverse-probability-weighted, adjudicated under-capture estimate defined in §9, which requires the chart review and is **[PENDING ADJUDICATION]**.

Pre-specified secondary and sensitivity variants of the recovery share: steatosis excluding alcohol-related codes 80.9%; steatosis with at least one cardiometabolic criterion (MASLD-consistent) 81.4%; steatosis excluding all competing etiologies (a NAFLD-era comparison, explicitly **not** primary under current nomenclature) 83.4%. Restricting to the discharge-summary-only population gives 81.06% under (b); counting Tier C hedged mentions as positive gives 82.23% under (b), adding 575 admissions; removing 571.9 gives 81.98%. Subject-grain collapse (a subject is code-positive if any admission is, and note-positive if any admission is) gives, under (b), 3,292 / 11,709 / 383 / 145,735 across 161,119 subjects.

## 8. Imaging denominator

Because the liver must be imaged before steatosis can be observed incidentally, the imaging denominator was characterized explicitly (`docs/imaging_denominator.md`). Under the primary −365/+30 window, admissions split into 24,192 (6.5%) with no radiology at all, 211,197 (56.5%) imaged but with no liver-inclusive study, and **138,603 (37.1%) with at least one liver-inclusive study**; the inpatient-linked-only split is 64,548 (17.3%) / 225,910 (60.4%) / 83,534 (22.3%).

Non-observation is predominantly **indication-driven**. Liver-inclusive imaging rate tracks the principal-diagnosis ICD chapter as clinically expected, from 11.3% (Eye) and 15.3% (Mental) and 19.0% (Musculoskeletal) up to 56.3% (Neoplasms), 60.2% (Infectious) and 70.0% (Digestive). Length of stay contributes partially (27.1% at < 1 day rising to 46.3% at ≥ 6 days) but explains only part of it: 80% of non-imaged admissions are not short-stay.

A **residual access/context component** remains after indication is held constant. Within abdominal-plausible chapters (circulatory, digestive, endocrine/metabolic, infectious, neoplasms; n = 171,410), the maximum one-versus-rest |SMD| for imaging rate did not shrink but grew — race 0.277 → 0.381, insurance 0.058 → 0.177. The direction is mixed rather than a simple disadvantage gradient: several immigrant- and language-associated groups image higher, while UNKNOWN, UNABLE TO OBTAIN, PATIENT DECLINED TO ANSWER and Medicare image lower. The coding-status imaging differential remains large within chapter (SMD +0.736 unadjusted → +0.663 within-chapter), consistent with an imaging → incidental-finding → code pathway.

Restricting the cross-tabulation to the imaging-observed population gives A 3,739 / B 19,248 / C 335 / D 115,281 and a recovery share of 83.7%, versus 81.9% in the full population — a movement of +1.8 points. Because the recovery share conditions on note-positivity, which already requires documentation, it is largely insensitive to the imaging denominator. Whether the imaging-observed population becomes primary is therefore consequential for the Aim 1b modelling population (where it is a pre-specified secondary population) rather than for the headline share. **Primary-population choice: unchanged (full locked population).**

## 9. Reference standard

Human chart adjudication is the irreducible reference standard here because it is the only label independent of both methods under comparison: judging the ICD gap against an ICD-derived truth collapses the gap to zero by construction, and judging the notes arm against a notes-derived truth is circular (`docs/reference_standard.md`).

**Sampling frame and allocation.** The 2×2 under the primary definition (b) is the sampling frame; the code−/note+ cell is the recovery zone and is largest by design. Four hundred charts were drawn with seed 20260818, allocated code−/note+ 150, code+/note+ 80, code+/note− 70, code−/note− 100. Blinded review IDs R0001–R0400 were assigned after a seeded shuffle, so neither the identifier nor the row order encodes cell membership.

**Weights.** Sampling is disproportionate, so each cell is reweighted to its population frequency: weight = N_pop(cell) ÷ n_sample(cell), giving 62.8375 (A), 151.9933 (B), 10.1857 (C) and 3454.53 (D). Cell sizes and per-cell sampling fractions are stored at sampling time, without which the reweighting could not be reconstructed.

**Blinding and double review.** Reviewers are blinded to code status, to note-trigger status and to cell membership. One hundred charts (25%) are independently adjudicated by both reviewers, flagged only in the untracked master key; Cohen's kappa is computed on the collapsed binary outcome and a weighted kappa on the four ordinal levels. The built overlap is a simple random draw of 100 from the 400, i.e. proportional to the cell allocation rather than 25 per cell; if per-cell kappa is wanted, a stratified overlap would be needed instead, and this is flagged for decision.

**Estimator and variance.** The headline Aim 1a quantity is the population-weighted share of adjudicated steatosis-positive admissions that are code-negative:

  under-capture = (w_B x_B + w_D x_D) ÷ (w_A x_A + w_B x_B + w_C x_C + w_D x_D),

with x_c the adjudicated positives in cell c. The note-rule PPV (cells A and B) and rule sensitivity are computed alongside. Implementation: `scripts/aim1a_estimator.py`, with unit tests reproducing a hand-checked target exactly (x = 76/128/35/1 → under-capture 81.698%, PPV 87.08%, sensitivity 86.409%). Uncertainty is quantified by a stratified bootstrap resampling within cells (500 replicates) and by a linearized interval, with a logit-scale linearized interval also carried so bounds are respected.

A pre-adjudication simulation of the estimator (`docs/aim1a_precision_forecast.md`; 2,000 simulated adjudications per scenario, seed 20260925) establishes the design-stage precision. Its central finding is that **cell D dominates the variance**: each of the 100 charts in cell D stands for approximately 3,455 admissions, so one additional adjudicated positive in D moves the estimate by 2–3 percentage points, against roughly 0.1 points for one in B; once the D positive rate reaches 3 per 100, 92–97% of the linearized variance comes from D alone. Bootstrap coverage is nominal at D = 0, falls to 63–65% at 1 positive per 100 (because 36–38% of adjudications then observe no D positive at all and the interval has nothing to resample in that cell), recovers to approximately 85% at 2 per 100 and approximately 92% at 3 or more. If the actual adjudication finds 0 or 1 positives among the 100 code−/note− charts, the headline interval will be accompanied by an explicit one-sided upper bound on the cell-D prevalence (rule of three: p_D < 3% with 95% confidence when x_D = 0, i.e. up to approximately 10,000 unobserved positives in that cell) rather than presented as a calibrated 95% interval. Rule sensitivity is much less precise than under-capture (bootstrap interval 20–40 points wide once D > 0) because every D positive enters its denominator at weight approximately 3,455; note-rule PPV is not exposed to cell D and its interval is 6–11 points wide.

**Adjudication criteria — `[PENDING clinician sign-off]`.** The criteria are Draft 1 (`docs/adjudication_criteria.md`) and are **not frozen**. The primary question is *"Is there evidence of hepatic steatosis during or before this admission?"*, answered on a five-option scale (Definite / Probable / Possible / Absent / Insufficient information) with a draft positive collapse of Definite + Probable. The evidence hierarchy is: liver biopsy reporting steatosis → Definite; CT or MRI reporting hepatic steatosis, fatty liver, fatty infiltration or decreased hepatic attenuation → Definite; ultrasound reporting increased hepatic echogenicity consistent with steatosis → Probable; a clinician's statement without supporting imaging in the packet → Probable; hedged radiology → Possible; elevated transaminases or metabolic risk alone → Absent for this question. Temporality (during / before / both) is recorded separately; an explicit newer negative study may override an older positive finding only on the reviewer's reliability judgement, with the reasoning recorded. Secondary questions, asked only when Definite or Probable, cover cardiometabolic risk (thresholds matched to the computable operationalization in §6), alcohol, and other identifiable causes of steatosis. Eight decisions (D1–D8) remain open for the reviewing clinician, including the response scale and positive collapse, whether an explicit radiologist statement on ultrasound raises to Definite, whether hedged imaging counts as Probable, the negation-override rule, the alcohol response format, and the disagreement-resolution mechanism. The criteria may be revised **once**, at the 20-chart training round, after which they are frozen for the formal review. **No chart from the 400-chart sample may be adjudicated until the criteria are signed off: [PENDING clinician sign-off].**

**Packet contents and leak checks.** Each reviewer receives one plain-text packet per chart (`docs/adjudication/packet_specification.md`): a header with age (capped at "89 or older"), sex and length of stay; the full verbatim discharge summary; all linked radiology reports plus the subject's outpatient reports within −365/+30 days, with exam names; ten laboratory analytes from explicit serum itemids; vitals and anthropometrics from `omr` within the same window; and medication orders. Stripped by construction: note, subject and admission identifiers; calendar dates (all times are day offsets from admission); ICD codes and coded problem lists; race, insurance, language and marital status; cell membership; and the note rule's output or any highlighting of trigger terms. Withholding race, insurance and language from the packet while retaining them at the analysis level protects the equity analysis from reviewer bias. A dry run generated all 420 packets (400 sample + 20 training), ran automated leak checks and then deleted the directory. Every structured-field leak test that must be zero was zero: phenotype-code long titles, demographic labels, 8-digit integers, cell labels, markup tokens and the chart's own identifiers. ICD-shaped patterns in structured text resolve entirely to numeric laboratory values, signed day offsets and drug names once those columns are removed (0 remaining ICD-9-shaped hits); the only residual candidates are 13 occurrences of a vitamin-name fragment in the medication table and fewer than 11 of a second, listed for a targeted grep before final release. Narrative hits (the word "recovery" in 53 files, `**`/`[[` markup in 80) are clinician-written text kept verbatim by design, not highlighting. Discharge text was verified byte-count-identical to the per-note index for all 420 charts.

**Availability of packet elements** across the 400 sampled charts: discharge summary present 89.2%, any radiology report 95.8%, at least one liver-inclusive report 60.5%, at least one of the ten labs 86.2%, BMI 71.5%, blood pressure 66.8%, at least one prescription 92.5%. ### 10.1 The silver label and its known error

Models are developed against a **silver label**: note-positive under the primary definition (b). The silver label is produced by the frozen lexical rule, is not adjudicated truth, and is the object under indictment in this study rather than a trusted target. Every development metric in this section carries that caveat, and final performance requires the gold standard. The size of the drop from silver-label to gold-standard performance is itself a pre-committed measure of silver-label error.

### 10.2 Splits and the gold-holdout rule

Splitting is by **subject**, never by admission, because one person contributes many admissions and splitting by admission would let a model memorize the person. GOLD_SUBJECTS is every subject with any admission in the 400-chart sample or the 20-chart training set; all their admissions form GOLD_HOLDOUT. Of the remaining subjects, 20% form TEST (touched once per model) and 80% form DEV, split into five subject-level folds (seed 20260920).

### 10.3 Feature sets and the leakage audit

Structured features are time-bounded at discharge: no post-discharge information, and only outpatient radiology *before* admission (the −365 lookback) contributes a feature. Every feature was classified as clinical or availability/volume, and the exclusions were recorded as an explicit leakage audit (`docs/run_2026-09-19/results/feature_classification.json`; 373,992 rows).

- **FS-B (clinical, 52 features).** Demographics and administrative context (age, sex, admission type, admission location, ICD era, length of stay, admission year, marital status); first and last in-admission values for ten analytes (ALT, AST, platelets, triglycerides, HDL, HbA1c, glucose, albumin, total bilirubin, alkaline phosphatase); pre-admission 365-day values for HbA1c, triglycerides and HDL; outpatient BMI, systolic and diastolic blood pressure; the five cardiometabolic criterion flags; qualifying medication-class flags (insulin, metformin, oral antidiabetics, beta-blockers, qualifying and excluded antihypertensives, lipid-lowering); the liver-excluded Charlson index; and etiology flags (alcohol, viral, cirrhosis, hepatocellular carcinoma, other).
- **FS-AVAIL (availability and volume, 42 features).** Per-analyte missingness indicators and result counts, total laboratory results, number of analytes available, number of diagnoses, prescription-order counts, note counts and character counts by source, and imaging indicators including liver-inclusive imaging inpatient, outpatient pre-365 and any-pre.
- **FS-A** is the union of FS-B and FS-AVAIL (94 features).

**Excluded, with the reason recorded:** the phenotype code itself (it is the label axis of the comparison); race, insurance and language (equity strata, retained for subgroup reporting but never features); GGT and its missingness indicator (0.9% coverage); `hospital_expire_flag` (post-discharge outcome information); `discharge_location` (discharge-time disposition, excluded as outcome-like); raw timestamps; cleaning flags; the **full Charlson index**, because Quan's mild-liver category contains K76.0, 571.8 and 571.9 and therefore leaks the code axis into a model whose label is the note axis; every note-rule output (the label source); and double-review and cell membership (sampling design). The Charlson leak was quantified: the project's index and `comorbidipy` (Quan et al., *Med Care* 2005;43(11):1130-9, PMID 16224307, with Charlson et al. 1987 weights, *J Chronic Dis* 1987;40(5):373-83, PMID 3558716) agree on 100.0% of 373,992 admissions, and the recovery-zone-versus-concordant SMD of −0.356 **collapses to +0.004** once the two liver categories are removed — the entire apparent comorbidity gap between the recovery zone and the concordant cell was the phenotype code itself (`docs/charlson_validation.md`). `charlson_noliver` is the variable used for modelling.

The FS-A versus FS-B contrast is itself a pre-committed result about the data (hypothesis H1b-i): the expectation recorded before fitting was that with availability and volume features included the top attributions would be dominated by laboratory-availability indicators and diagnosis count rather than clinical values, and that excluding them would cost discrimination and shift attribution toward clinical values.

**Observed** (`docs/run_2026-09-19/results/aim1b_structured.json`, field `shap`; mean absolute SHAP value on a 20,000-admission TEST subsample, CatBoost unweighted). The discrimination gap is large: TEST AUROC 0.857 under FS-A versus 0.787 under FS-B, and AUPRC 0.380 versus 0.282. The single most attributed feature under FS-A is an availability feature — **`liver_imaging_any_pre`, mean |SHAP| 0.675**, roughly double the next feature — followed by `age` 0.336, `omr_BMI` 0.225, `liver_imaging_out_pre365` 0.206 (availability) and `cmrf_overweight` 0.197. But **availability features make up only 28% of the top 25 by mean |SHAP| under FS-A**, so the recorded expectation that availability indicators and diagnosis count would *dominate* the attribution ranking is only partly borne out: one availability feature dominates, the rest of the ranking is mixed, and `n_diagnoses` sits fifteenth (0.062). Under FS-B, attribution shifts to clinical values as expected — `age` 0.356, `omr_BMI` 0.180, `cmrf_overweight` 0.159, `icd_era` 0.157, `first_val_ALT` 0.124 — with an availability share of 0.00 by construction. FS-AVAIL alone reaches TEST AUROC 0.812 and AUPRC 0.245, i.e. availability and volume information *by itself* discriminates better than the whole clinical feature set does on AUROC, which is the substantive finding of this comparison and belongs in the discussion rather than being treated as a modelling result.

### 10.4 Imbalance variants, learners and tuning

Three imbalance variants are trained and reported side by side for every learner and feature set, rather than one being chosen: **unweighted**; **weighted** (`scale_pos_weight` = negatives ÷ positives within the training fold); and **weighted with analytic prior correction** (the weighted model's logit shifted by −log(w), requiring no additional fit). This was an amendment dated before any model was trained (amendment (b)), because class weighting inflates predicted risk for the same reason synthetic oversampling does, so the recorded expectation of calibration slope near 1 and intercept near 0 under weighting is tested rather than assumed.

Learners: **CatBoost** (primary), **XGBoost** and **LightGBM**, each with 1,000 boosting rounds and early stopping after 50 rounds. Tuning: four random configurations per learner (learning rate, depth, L2 regularization, minimum child weight), evaluated on FS-A unweighted by three-fold subject-level cross-validation within DEV (folds 0–2 of the five), with early stopping on an inner 10% subject split so that no early-stopping decision is made on data used for scoring. Out-of-fold predictions use all five DEV folds. **TEST is touched once per model.** Uncertainty is a subject-cluster bootstrap with 500 replicates. Seed 20260919, four threads. A secondary modelling population restricted to imaging-observed admissions was pre-specified (amendment (e)): within admissions where the liver was imaged, the question becomes whether structured data predicts *documented steatosis* rather than *who got imaged*.

**Selected configurations** (four random configurations per learner, ranked by mean DEV out-of-fold AUPRC on FS-A unweighted): CatBoost learning rate 0.05, depth 8, L2 10 (0.387); XGBoost learning rate 0.05, depth 8, L2 5, minimum child weight 10 (0.383); LightGBM learning rate 0.08, depth 6, L2 10, minimum child weight 5 (0.384). The four configurations per learner spanned a narrow range (0.373–0.387), so the tuning choice is not consequential and should be reported as such. Total runtime 3,953 seconds.

**Structured-arm results** (`docs/run_2026-09-19/results/aim1b_structured.json`; TEST n = 75,124 with 5,426 silver-positive; 95% intervals are 500-replicate subject-cluster bootstraps). Tabulated in `docs/manuscript_results_skeleton.md` Table 4b. Three points carry the section:

1. **Feature-set gap.** CatBoost TEST AUROC 0.857 (0.849–0.866) on FS-A, 0.812 (0.803–0.820) on FS-AVAIL and 0.787 (0.778–0.796) on FS-B; AUPRC 0.380, 0.245 and 0.282 respectively. XGBoost and LightGBM reproduce this ordering closely (FS-A AUROC 0.858 and 0.857; FS-B 0.787 and 0.788). Restricted to code-negative TEST admissions (n = 74,109, 4,555 positive), CatBoost gives AUROC 0.857 / AUPRC 0.323 on FS-A versus 0.777 / 0.228 on FS-B.
2. **Class weighting hurts calibration and the analytic correction repairs it exactly, without touching discrimination.** For CatBoost the weighted calibration intercept is −2.378 (FS-A), −2.425 (FS-B) and −2.496 (FS-AVAIL); the analytic prior correction returns it to 0.175, 0.141 and 0.063 with AUROC and AUPRC unchanged to three decimals, as it must, since the correction is a monotone logit shift. The pre-committed expectation of slope near 1 and intercept near 0 *under weighting alone* is therefore **not** supported. For LightGBM the weighted variants additionally distort the slope (3.038 on FS-A, 3.478 on FS-B) and lose substantial AUPRC (0.267 and 0.180), so weighting is not benign for that learner; XGBoost's weighted slope falls to 0.790 and 0.736. The unweighted models are already well calibrated (CatBoost FS-A intercept 0.031, slope 1.018).
3. **Secondary imaging-observed population** (amendment (e); DEV 109,220 with 17,559 positive, TEST 27,602 with 4,493 positive). CatBoost unweighted: FS-A AUROC 0.766 (0.754–0.778) / AUPRC 0.426 (0.403–0.453); FS-B AUROC 0.750 (0.738–0.763) / AUPRC 0.402 (0.378–0.427). AUROC falls and AUPRC rises relative to the full population, and the FS-A advantage narrows sharply (0.016 AUROC, against 0.070 in the full population) — consistent with much of the FS-A advantage in the full population being the model learning *who got liver imaging* rather than who has documented steatosis.

Operating-point summary at the DEV out-of-fold maximum-F1 threshold, reported descriptively and not proposed for use: CatBoost FS-A unweighted, threshold 0.208, DEV out-of-fold F1 0.408, TEST sensitivity 0.479, specificity 0.936, positive predictive value 0.368; CatBoost FS-B unweighted, threshold 0.156, F1 0.340, sensitivity 0.408, specificity 0.918, positive predictive value 0.279. Subgroup metrics were computed per stratum with small strata marked "not estimable" rather than merged, and a per-stratum flag for a material calibration difference; these are reported in the results document.

### 10.5 Notes arm

**Text assembly.** Per admission, under the primary linkage: discharge summary plus inpatient radiology plus the subject's outpatient radiology within −365/+30 days. Priority order within a 22,000-character budget (approximately 12 chunks of 512 tokens at roughly 3.6 characters per token for clinical text): liver-inclusive radiology reports in full, then the IMPRESSION section of other radiology reports, then discharge-summary sections in the order Discharge Diagnosis, Past Medical History, Pertinent Results, Brief Hospital Course, History of Present Illness, Chief Complaint, Impression, Abdomen, Social History, Major Surgical Procedure, then remaining sections in document order with boilerplate skipped. The budget was sized from the corpus section-length distribution so that the steatosis-bearing sections fit in full for nearly every admission; 7.2% of assembled texts reached the budget.

**Three text variants**, all using the frozen rule's own lexicon and sentence splitter, imported rather than copied:
- **U** — unmasked text.
- **M** — every lexicon regex match, **all tiers and any assertion status**, replaced by a mask token.
- **S** — every sentence containing any lexicon match deleted, asking whether the *rest* of the documentation carries signal.

**Masking deliberately ignores assertion status.** If only affirmed mentions were masked, the mask itself would encode the label: the presence of a mask would mark exactly the admissions the rule called positive. Masking every match regardless of assertion removes that particular shortcut, but it does not remove all of them, and the results below show why.

**The circularity is structural and is reported as such.** The silver label is a lexical rule applied to the same text a notes model reads, so a notes model can score near-perfectly by relearning the lexicon. Nothing in this phase is an accuracy estimate.

**TF-IDF development diagnostic** (`docs/aim1b_notes.md`, `docs/run_2026-09-19/results/aim1b_notes_tfidf.json`). Word 1–2-grams, minimum document frequency 100, sublinear term frequency, L2-penalized logistic regression with C fixed at 1; vocabulary fit **inside** training folds only; GOLD_HOLDOUT scored, never fitted. Subsample: DEV 23,816, TEST 6,164, GOLD_HOLDOUT 2,865. TEST performance (unweighted):

| Variant | AUROC (95% CI) | AUPRC (95% CI) | Brier | Calibration slope |
| --- | --- | --- | --: | --: |
| U (unmasked) | 0.896 (0.862–0.937) | 0.596 (0.518–0.674) | 0.038 | 1.444 |
| M (masked) | 0.912 (0.887–0.940) | 0.616 (0.538–0.691) | 0.037 | 1.536 |
| S (sentence-deleted) | 0.826 (0.788–0.869) | 0.407 (0.326–0.488) | 0.047 | 1.126 |

Variant U's top positive coefficients are the lexicon itself (`steatosis` 11.74, `fatty` 11.45, `fatty liver` 9.43, `hepatic steatosis` 9.09, `nash` 5.90) — that table is the demonstration of circularity, not a finding. Variant M's dominant term is the mask token itself (coefficient 22.77, document frequency 2,599) with its bigrams behind it, which is why M scores at least as high as U: masking every match still leaves *the presence of a match* as a feature. Variant S is the informative row: with every lexicon-bearing sentence removed, the remaining text still discriminates (`cirrhosis` 4.11, `liver disease` 4.02, `forms of` 3.73, `fibrosis` 3.63, `obesity` 1.72) — the company steatosis keeps, and what a notes model could legitimately learn. Within code-negative TEST admissions only (n = 6,057, 286 positive), unweighted AUROC is 0.907 (U), 0.916 (M) and 0.833 (S). Class weighting moves the S calibration slope from 1.126 to 0.950; the analytic prior correction restores the intercept (from −2.059 to 0.494) without changing AUROC or AUPRC.

**Embedding arm.** Admission text is encoded with frozen **Bio_ClinicalBERT** (Alsentzer et al. 2019 — **unverified reference**, see `docs/references/unresolved.md` entry R09), `trust_remote_code=False`, Hugging Face telemetry disabled: 512-token chunks, stride 64, at most 12 chunks, attention-masked mean pooling per chunk, and an admission vector formed as the concatenation of the per-chunk mean and max, giving 1,536 dimensions in float16. Heads: L2 logistic regression and LightGBM on the frozen vectors, with the better on DEV out-of-fold AUPRC kept. A notes-augmented model adds the first 64 principal components of the embeddings to FS-B in CatBoost, with **PCA fit inside training folds only**. **Embedding-arm results: [PENDING — job still running at draft time; expected in `docs/run_2026-09-19/results/aim1b_notes_arm.json`].**

### 10.8 Every deviation from the plan

1. **Chunked Bio_ClinicalBERT instead of Clinical-Longformer.** The methods plan named Clinical-Longformer (Li et al. 2022 — **unverified reference**, `docs/references/unresolved.md` entry R10) for long documents. All text was instead encoded with chunked Bio_ClinicalBERT because long-attention models are slow or unsupported on the available hardware. Recorded as D-02; options include keeping chunked BERT and describing it as such, re-running later on other hardware with the same splits, subsample and variants, or dropping the transformer arm entirely. **[PENDING researcher decision D-02].**
2. **CPU instead of Metal Performance Shaders.** torch 2.11.0 reports MPS as built but `is_available()` is False on the host macOS 13.3.1. All encoding and training ran on CPU with 8 threads. No torch downgrade was attempted.
3. **Subsample size, chosen from a measured pilot.** A pilot encoded 200 DEV admissions of variant S with Bio_ClinicalBERT on CPU: 613,456 tokens in 107.7 seconds, 5,694 tokens/second, 0.539 seconds per admission (`docs/run_2026-09-19/results/embed_pilot.json`). Against a 5-hour embedding budget this projected a maximum of 33,414 admissions. The draw was a simple random sample of 13,000 DEV+TEST **subjects** (seed 20260922) giving 29,980 admissions, plus all 2,865 GOLD_HOLDOUT admissions, for 32,845 encoded admissions; the TF-IDF diagnostic used DEV 23,816 / TEST 6,164 / GOLD 2,865 of these. Median assembled length 9,445 characters; 39% carry a liver-inclusive report.
4. **LightGBM and XGBoost OpenMP workaround.** Both wheels link `@rpath/libomp.dylib`, which is absent system-wide, and system-level installation was not permitted. A ctypes preload failed on rpath resolution. Both load correctly when `DYLD_LIBRARY_PATH` points at the libomp bundled inside the torch wheel, so all modelling scripts are launched through `scripts/run0919_env.sh`, which sets that variable. No system change was made.
5. **Test-harness wrapper.** The project's frozen rule test file is a plain script, not pytest-discoverable, so `pytest` initially collected zero tests. A thin wrapper parametrizes over the frozen file's case list by parsing it; **the frozen file was not modified**.
6. **Tracked tables are Markdown and JSON.** `*.csv` is git-ignored project-wide, so every tracked table is a Markdown file with a JSON results file behind it.
7. **Availability under an outpatient window includes outpatient laboratory results.** The plan did not state how "availability under a window" should treat labs without an admission linkage; the natural reading was adopted and stated in the document.
8. **TF-IDF regularization not tuned.** C was fixed at 1.0 for the development diagnostic.
9. **Post-tag change to the frozen rule file.** `scripts/note_phenotype.py` differs from its v1.1.0 tag by two lines: a hard-coded population path replaced by an import of the project population constant. Lexicon, context handling and classifier logic are byte-identical to the tag. No tag was created or moved.
10. **Citation list built from the repository rather than from the supplied bibliography.** The intended citation appendix was truncated in transmission and never received, so the citation registry was assembled from citation strings present in the repository's own documents and script docstrings, then verified against PubMed and Crossref. Four references remain unresolved (`docs/references/unresolved.md`) and must be cited as author–year with an unverified note until confirmed.
11. **Phase 1.2 skipped** as verified-existing: the adjudication criteria Draft 1 was already stored with its open-decision table and linked from the reference-standard specification.
12. **Jensen gap in the estimator simulation** (documented, not a deviation from procedure): the simulated mean of the ratio estimator sits 0–0.5 percentage points below the plug-in closed form whenever cell D contributes positives, because the estimator is concave in x_D. This is a property of the ratio estimator at 100 charts in cell D, not a coding error.

## 11. Equity audit (Aim 1c, level 1)

The level-1 audit asks whether the gap between notes and codes is the same size in every group, at the computable stage (`docs/aim1c_level1.md`; results `docs/run_2026-09-19/results/aim1c_level1.json`). Levels 2 (weighted PPV by stratum against the gold standard) and 3 (model calibration by stratum) require the adjudication and the models and are **[PENDING ADJUDICATION]** and **[PENDING — models still running]** respectively.

**Strata as recorded, never collapsed.** Race is analysed at its full recorded granularity (33 levels), not collapsed to top-level groups, because payer mix and laboratory availability vary sharply within the hierarchy and collapsing would blur exactly the structure the audit is looking for. Language is likewise analysed as recorded (26 levels). UNKNOWN, UNABLE TO OBTAIN and PATIENT DECLINED TO ANSWER are reported but marked as **encounter characteristics, not population groups**. Ages ≥ 89 are recoded to 91 in MIMIC-IV, so the 89+ band is an aggregate. Insurance, sex and age band complete the stratum list.

**Small-cell floor of 11.** No recovery share is reported where the code−/note+ cell has fewer than 11 admissions, and no corroboration share where code+/note+ plus code+/note− has fewer than 11. Every stratum's four cell counts are printed **before** any rate. Strata below the floor are **declared non-analyzable, not merged** with neighbours.

**Uncertainty.** Ninety-five percent intervals are **subject-cluster bootstraps** with 500 replicates: a subject's admissions are resampled together, because one person can contribute several admissions and treating them as independent would understate the interval. An interval wider than 20 percentage points is explicitly marked as too wide to support a claim — an analyst threshold, stated so that it can be argued with. No p-values are reported; the one-versus-rest standardized mean difference in the coding rate among note-positive admissions is given as a descriptive contrast.

**Headline pattern.** The recovery share lies between roughly 61% and 96% across analyzable strata, with most large strata between 78% and 86%. By race, 33 of 33 levels are analyzable and 21 have intervals narrow enough to support a claim: WHITE 82.4% (81.5–83.2), BLACK/AFRICAN AMERICAN 85.7% (84.1–87.1), HISPANIC/LATINO – PUERTO RICAN 72.6% (68.0–76.5) with a coding-rate SMD of +0.23 versus the rest. By insurance: Medicare 82.2%, Private 80.2%, Medicaid 83.6%, Other 85.6%, all with intervals no wider than 5.3 points. By sex: male 82.7%, female 81.1%. By language, 17 of 26 levels are analyzable and 10 claim-supported, with Spanish at 77.8% (74.4–80.8). By age band, all six are analyzable, and the 89+ corroboration share of 72.6% carries a 32-point interval and is reported as not supporting a claim. The direction is **not uniform**: some groups with thinner structured records show higher recovery shares (more of their documented steatosis is uncoded) and some lower. Mechanism measures (laboratory availability, liver-inclusive imaging rate, cardiometabolic unascertainability) are tabulated alongside every stratum.

**Exploratory adjusted model.** One generalized estimating equation was fitted among note-positive admissions with code-positive as the outcome, binomial link, exchangeable working correlation, clustered on subject, n = 27,826. Covariates were fixed **before fitting** in amendment (g) of the pre-specification commit: race as recorded, insurance, sex, age band, admission type, ICD version of the admission, and note source (discharge, inpatient radiology, outpatient radiology). **Diagnosis count and laboratory availability are deliberately not adjusted for: they are the proposed mechanism**, and conditioning on a mediator would remove precisely the pathway the study argues for. The model is labelled exploratory everywhere: its adjusted odds ratios describe association in the computable data and are **not** estimates of adjudicated under-coding by group. Notable estimates include HISPANIC/LATINO – PUERTO RICAN 1.60 (1.31–1.96), HISPANIC/LATINO – GUATEMALAN 2.04 (1.28–3.26), Private insurance versus Medicare 1.35 (1.21–1.52), surgical same-day admission versus emergency 2.91 (2.56–3.30), ICD-10-only era 1.40 (1.28–1.54), and discharge-summary note source 16.75 (14.65–19.15).

## 12. Statistical analysis

All comparisons are descriptive. **No p-values are reported anywhere in this study.** Where a contrast between groups is useful, a standardized mean difference is given, with |SMD| > 0.1 flagged as imbalance; SMDs for categorical variables with more than two levels are multinomial.

**Bootstrap procedures.** Aim 1c stratum shares use a subject-cluster bootstrap with **500 replicates** (a subject's admissions resampled together), seed 20260919. Aim 1b model metrics use a subject-cluster bootstrap with **500 replicates** on AUROC, AUPRC and Brier score. The Aim 1a estimator uses a **stratified bootstrap resampling within sampling cells, 500 replicates**, alongside a linearized interval and a logit-scale linearized interval; the design-stage simulation drew **2,000 simulated adjudications per scenario** with an internal 500-replicate bootstrap, seed 20260925. Calibration is reported as intercept and slope from a logistic recalibration of the linear predictor, not as a single summary statistic.

**Small-cell policy.** Any reported cell below 11 is written as `<11` in every tracked artefact. Where an exact small number is needed for a decision it is written only to an untracked private folder. This policy is applied uniformly, including to the packet leak-check tables and to the 571.9 sample-movement counts.

**Seeds** are fixed and recorded: chart sample 20260818; reviewer-training draw 20260919; subject split 20260920; reviewer assignment 20260921; notes subsample 20260922; precision simulation 20260925; model fitting 20260919.

**Software.** Python 3.14.4 on arm64 (Apple M1 Max, 32 GB RAM), CPU only. ## 13. Limitations

1. **The note-module coverage exclusion, whose mechanism is not fully characterized.** Requiring at least one linked note removes 171,505 of 545,497 admissions (31.4%), and removes code-positive admissions preferentially (−37.2%). The exclusion decomposes into 100,029 admissions whose subject is absent from MIMIC-IV-Note entirely (a release-lineage property, external to the encounter and to the coder) and 71,476 admissions whose subject has notes elsewhere but none on this stay (an encounter-level property concentrated in short observation stays). **Why a given subject is absent from the note release is not established by this study.** The second component is demonstrably differential by coding status (SMD +0.138), by admission type, by length of stay and by insurance. The restriction is therefore not missing-completely-at-random, and the equity audit must be read with that in mind. An earlier internal analysis attributed the pattern to a temporal release window; that attribution is superseded (§2) and the residual mechanism is uncharacterized.
2. **Alcohol is proxied by disorder-level ICD codes, so MetALD thresholds cannot be applied.** The consensus MetALD definition rests on quantified weekly intake (140–350 g/week in females, 210–420 g/week in males). MIMIC-IV contains no quantified intake. Every MetALD count in this study is a code-based proxy for disorder-level use, not an implementation of the criterion, and the moderate-intake band the definition targets is precisely the band codes do not capture. MetALD also has no ICD code of its own, so the 4,308 MetALD-consistent note-positive admissions are invisible to the code axis by construction.
3. **Medication exposure is from orders only.** Treatment status is derived from `prescriptions`, MIMIC-IV's medication-order table. Dispensing-level detail (`pharmacy`) was not obtained, so adherence and dosing cannot be assessed, and inpatient orders cannot in general be distinguished from continuation of home therapy — the reason insulin and beta-blockers were excluded from the cardiometabolic criteria.
4. **The age cap.** MIMIC-IV recodes ages ≥ 89 to 91. The observed `anchor_age` maximum of 91 is an artefact, the 89+ stratum is an aggregate of a heterogeneous group, and no analysis of the oldest patients at finer resolution is possible.
5. **Non-observation of the liver.** Only 138,603 of 373,992 admissions (37.1%) have any liver-inclusive imaging in the −365/+30 window; 56.5% are imaged elsewhere and 6.5% not at all. Steatosis cannot be documented in an organ that was never imaged, so the note axis is conditioned on an imaging process that is itself differential — predominantly by indication, but with a residual access/context component that grows rather than shrinks when indication is held constant (§8).
6. **Triglycerides and HDL are unascertainable for roughly 60% of admissions.** Under the five-criterion operationalization, hypertriglyceridaemia is unascertainable for **60.1%** and low HDL for **61.8%** of the locked population (no code, no measurement, no qualifying medication). The cardiometabolic half of the MASLD definition therefore rests disproportionately on the three well-ascertained criteria, and unascertainability is itself differentially distributed across strata.
7. **Negation and context handling were reimplemented, not run from the reference distribution.** ConText and NegEx were reimplemented in-repository using the published trigger lexicons, for Python 3.14 reproducibility and to avoid an external dependency. The implementation is unit-tested against synthetic cases and its behaviour is documented, but it is not the authors' own distribution, and residual divergence from the reference implementation cannot be excluded. Chart-level negation judgements by reviewers (where a newer normal study may override an older positive) also operate at a different level from the rule's sentence-level negation; such disagreements are part of what Aim 1a measures rather than error.
8. **Single centre.** MIMIC-IV is one academic medical centre. Coding practice, documentation culture, imaging availability and payer mix are all local, and the under-capture gap is not transportable without external validation.
9. **Silver-label circularity for the notes arm.** The notes arm is developed against a label produced by a lexical rule over the same text the model reads. Development metrics for the notes arm are not accuracy estimates; variant U's coefficients are the lexicon, and masking every lexicon match still leaves the presence of a match as a feature (variant M). Only the gold standard can break this, and only variant S (every lexicon-bearing sentence deleted) speaks to what the rest of the documentation carries.
10. **Chunked BERT in place of a long-document model.** Discharge summaries reach 60,381 characters, well beyond a 512-token window. Encoding used frozen Bio_ClinicalBERT over 512-token chunks with mean+max pooling rather than a long-attention model, on CPU, because the available hardware did not support the planned approach. Cross-chunk dependencies are therefore represented only by pooling, and the transformer arm is a chunk-level approximation.
11. **The reference standard is sampled, not exhaustive, and cell D dominates its precision.** One hundred charts represent roughly 345,000 admissions in the code−/note− cell, so the headline interval is governed by how many positives that cell contains, and at low true prevalence the interval undercovers (§9). This is a design-stage fact that no estimator can repair.
12. **The gold standard does not yet exist.** No adjudicated estimate is available. Every quantity in this study that depends on it is marked `[PENDING ADJUDICATION]`, and no computable-stage share should be read as a substitute.
13. **This study is not registered with any public registry.** Its timing claims rest on the repository's git history: frozen, tagged rules before the cross-tabulation was built, and a pre-specification commit before any model was trained. Reviewers can verify that history only by inspecting the repository.
